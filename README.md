# AI BlogNest API

AI BlogNest API is a simple REST API developed using Node.js and Express.js.

## Features

* Create a blog
* View all blogs
* View a single blog
* Update a blog
* Delete a blog

## Technologies Used

* Node.js
* Express.js
* REST API
* JSON

## API Endpoints

| Method | Endpoint         | Description   |
| ------ | ---------------- | ------------- |
| GET    | `/api/blogs`     | Get all blogs |
| GET    | `/api/blogs/:id` | Get one blog  |
| POST   | `/api/blogs`     | Create a blog |
| PUT    | `/api/blogs/:id` | Update a blog |
| DELETE | `/api/blogs/:id` | Delete a blog |

## How to Run

```bash
npm install
node server.js
```

The API will run on:

`http://localhost:3000`
